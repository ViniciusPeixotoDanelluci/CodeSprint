---
title: Palindrominus
description: Default Palindrome Task
---

Dado um número inteiro *`x`* retorne *`true`* (verdadeiro), se *`x`* for um palindromo, e *`false`* (falso) caso contrário.

**Exemplo 1:**

```
    Input: x = 121
    Output: true
    Explicação: O número 121 lê-se da esquerda para a direita e da direita para a esquerda.
```

**Exemplo 2:**

```
    Input: x = -121
    Output: false
    Explicação: Da esquerda para a direita, lê-se -121. Da direita para a esquerda, torna-se 121-. Portanto, não é um palíndromo.
```

**Exemplo 3:**

```
    Input: x = 10
    Output: false
    Explicação: Lê-se 01 da direita para a esquerda. Portanto, não é um palíndromo.
```
